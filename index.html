DESCUENTOS POR PRONTO PAGO

Las multas de tráfico tienen un descuento del 50% si se pagan en los primeros 20 días naturales, siempre que no impliquen pérdida de puntos.

Las infracciones que conllevan pérdida de puntos no tienen descuento por pronto pago.

📡 GPS + OpenStreetMap

Esta app usa el GPS de tu dispositivo y consulta los límites de velocidad de OpenStreetMap (Overpass API) en tiempo real. La API es 100% gratuita y sin límites de uso.

Pulsa 🗺 OSM para forzar una consulta del límite de la vía donde estás.

📲 Cómo instalar como APK

  • Opción A — Chrome Android: menú ⋮ → Añadir a pantalla de inicio
  • Opción B — APK real: sube estos archivos a GitHub Pages (gratis) y usa PWABuilder.com para generar el .apk
  • Opción C — App directo: usa WebIntoApp.com con la URL de tu GitHub Pages

🪟 Ventana flotante

La ventana es arrastrable (toca el título) y redimensionable (arrastra la esquina inferior derecha).

En Android, para que se superponga a Google Maps o Waze, ve a Ajustes → Aplicaciones → SpeedGuard → Permisos → Aparecer encima de otras apps.
