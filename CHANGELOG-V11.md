# SpeedGuard Mobile V11

- Driving mode now has a dedicated no-touch radar HUD visible without scrolling.
- Automatic radar scanning preloads radars up to 8 km ahead using OpenStreetMap/Overpass.
- Added automatic average-speed section detection and automatic start before the section entry.
- Added direction filtering for average-speed sections when GPS heading is available.
- Added a fallback Overpass endpoint.
- Fixed radar scan interval reduced to 6 seconds while GPS is active.
- The active section shows progress, current speed and average speed in the driving HUD.
- Version label updated to V11 and service-worker cache bumped.
