# SpeedGuard V21

- Replaces the circular compass with a full-width driving heading ribbon.
- Displays current driving direction and relative direction of nearest radar (ahead/behind/left/right), radar bearing, distance and speed limit.
- Increases the typography across driving HUD, radar labels, speed-limit, road diagnostic and segment metrics.
- Uses the previously configured 2.5-second road query trigger; this remains dependent on GPS updates and Overpass response time, so actual refresh can be slower under network/API load.
- Service worker cache version bumped to V21.
